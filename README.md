# Snake Game

A classic Snake game built using Python and the Pygame library. The goal is to control the snake to eat food, grow longer, and avoid collisions with the walls or its own body.

## Features
- Simple and addictive gameplay
- Classic Snake game mechanics
- Score tracking
- Increasing difficulty as the snake grows

## Requirements

- Python 3.x
- Pygame library

## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/yourusername/snake-game.git
    ```

2. Navigate to the project directory:

    ```bash
    cd snake-game
    ```

3. Install the required dependencies:

    ```bash
    pip install pygame
    ```
